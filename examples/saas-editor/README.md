# Example: saas-editor

Intentionally small. Shows `ContentEditor` with the Blog and Docs content types, the live SEO analyzer, the preview, and in-memory content — no auth, no database, no TypeContent backend.

1. Create a Vite + React + TypeScript + Tailwind app and map `@/*` to `./src/*`.
2. Copy the editor source (`bun packages/cli/src/cli.ts add editor --cwd <your-app>` from a TypeContent checkout).
3. Use `src/App.tsx` from this folder.
